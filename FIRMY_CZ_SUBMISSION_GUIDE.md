**Firmy.cz does NOT provide a public API for creating individual business profiles.**

They only offer:
1. **JSON Feed API** - For businesses with 10+ branches (not applicable)
2. **Manual Web Submission** - The only option for single organizations

## 3. Verification Process

After submission:

1. **Email verification** - Confirm your email address
2. **Phone verification** - SMS code to verify phone number
3. **Profile review** - Firmy.cz reviews submission (1-3 business days)
4. **Approval notification** - Email when profile goes live

## 7. Troubleshooting

**Profile not appearing?**
- Wait 24-48 hours after approval
- Check if address is valid Czech location
- Verify all required fields are filled

**Can't verify phone?**
- Try different number format (+420 vs 00420)
- Use Czech number if available
- Contact support: podpora@firmy.cz

**Profile rejected?**
- Check spam folder for rejection email
- Common issues: Invalid address, inappropriate content, duplicate listing
- Resubmit with corrections
